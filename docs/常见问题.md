# 常见问题

## 安装

### 双击 bat 一闪而过 / 提示"无法加载文件，因为在此系统上禁止运行脚本"

Windows 默认的执行策略会拦 `.ps1`。本项目的 bat 已经带了 `-ExecutionPolicy Bypass`，正常不会触发。如果仍然报错，用管理员 PowerShell 执行一次：

```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

或者手动跑：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\installer\install.ps1
```

### 提示"没有找到 ROB RUN 的游戏目录"

脚本会读注册表 `HKCU\Software\Valve\Steam\SteamPath`，再解析 `steamapps\libraryfolders.vdf` 拿到所有 Steam 库。找不到通常是因为：

- 游戏装在非 Steam 库目录（比如手动移动过）
- Steam 装在非标准路径且注册表被清理过

指定路径即可：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\installer\install.ps1 -GamePath "D:\game\steamapps\common\Rob Run"
```

或者直接手动复制 `patch/` 里的 bundle 覆盖进去。

### 提示"检测到游戏正在运行"

ROB RUN 有 EAC 启动器（`start_protected_game.exe`），只关窗口不一定退干净。去任务管理器确认 `ROB RUN.exe` 和 `start_protected_game.exe` 都没了，或者干脆先退出 Steam。

### 装完提示文件大小不一致

几乎都是杀毒软件（火绒 / 360 / Defender）在复制过程中扫了文件并锁定。把游戏目录加入信任区后重试。

## 使用

### 装完进游戏还是英文

按顺序排查：

1. **确认文件真的换了**：`ROB RUN_Data\StreamingAssets\aa\StandaloneWindows64\` 下的 bundle 大小应该是 **273 KB** 左右（原版 138 KB，中文 UTF-8 每字 3 字节，所以文件会明显变大）。
2. **确认游戏内语言设置是 English**。这一点反直觉但很重要——我们替换的就是「英文」语言包。如果你在设置里切到别的语言，游戏会去加载 `french` / `german` 等其他 bundle，自然还是外文。
3. **确认没有多个游戏目录**。有些玩家装过两次游戏，Steam 实际启动的是另一个副本。
4. 如果装过又卸载过，确认 `.original_bak` 不在游戏目录里被误加载。

### 部分文字显示成方块 / 问号

说明字体缺字。ROB RUN 的 UI 字体是动态字体，正常情况下会自动回退到系统字体。如果出现方块：

- 确认系统装了中文语言包（Windows 设置 → 时间和语言 → 语言）
- 少数特殊符号（比如 `【】` 全角括号）在某些字体下可能缺字，这类可以直接改成半角

### 文字超出了按钮/框

中文比英文短，正常不会溢出；但因为中文不用空格断行，长句可能出现整段被推到下一行。如果发现明显错位，请提 Issue 并附截图，我们会缩短该条译文。

### 玩家名字 / 帮派名 / 聊天还是英文

这些是**动态内容**，来自服务器和玩家输入，不经过语言包。语言包只负责静态界面文本，改不了这些。

### 载入界面的小提示（Like "...connecting to Steam"）有没有翻

翻了，在术语表里统一成了「…正在连接 Steam」这类格式。

## 更新

### 游戏更新后变回英文

Steam 更新覆盖了 bundle。重跑一次 `安装汉化.bat`。

### 游戏更新后汉化包导致崩溃 / 界面乱码

说明文本结构变了（条目增删、字段变化），旧的汉化包和新的游戏版本不匹配。处理：

1. 跑 `卸载汉化.bat` 或 Steam 验证完整性，先保证英文版能进
2. 提 Issue 告知游戏版本
3. 或者自己重建：

```bash
python tools/extract.py --game "<游戏目录>" -o strings/strings_en.json
python tools/translate.py -i strings/strings_en.json -o strings/strings_zh.json
python tools/build.py --game "<游戏目录>"
```

## 安全

### 会不会被封号

诚实回答：**不确定，但风险较低**。

- 没有修改可执行代码，没有注入，没有内存挂钩
- 只替换了一个数据资源文件
- 社区内目前没有因换语言包被封的记录

但 ROB RUN 用 EAC，而官方没有开放 Mod 支持。如果未来加入资源哈希校验，替换的 bundle 会被识别为异常。**不放心就别装**，或者装了之后随时能一键还原。

### 补丁里会不会有病毒

- 全部源码在本仓库，可以逐行审
- 汉化 bundle 就是原版 bundle 改文本，可以用 `tools/extract.py` 自己解包对比
- 不包含任何 exe / dll

如果你从第三方渠道下载的「整合包」「绿色版」，那和本项目无关，风险自负。

## 卸载

### 怎么彻底还原

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\installer\uninstall.ps1
```

或者 Steam 库 → 右键 ROB RUN → 属性 → 已安装文件 → **验证游戏文件的完整性**。后者最彻底，会重新下载原版语言包。

### 卸载后进不去游戏

跟语言包无关，多半是 EAC 的问题。Steam 验证完整性 → 重启电脑 → 从 Steam 库启动（不要双击 exe）。仍然不行的话重装 EAC：游戏目录下 `EasyAntiCheat\EasyAntiCheat_Setup.exe` → 选 ROB RUN → Repair。
